How it works

A bridge, not an emulator.

The goal is not to hide TempleOS inside a virtual machine. It is to understand HolyC programs at the source level and give their useful ideas a native Linux home. Compatibility grows through real programs, not abstract checklists.

READ .HC SOURCE

The C++ frontend recognizes a focused, expanding subset of HolyC and reports unsupported constructs clearly.

TRANSLATE WITH INTENT

Supported language constructs become portable C while source locations remain connected to the original file.

MAP THE RUNTIME

TempleOS-style drawing, input, text, timing, and utility APIs are implemented safely on Linux.

RUN NATIVELY

Clang produces an ordinary Linux executable backed by SDL2—no guest operating system required.

About Bak-Lab

Curiosity made executable.

Bak-Lab is an independent open-source workshop exploring unusual systems, compact software, and the boundary between old ideas and modern machines.

The current mission is simple to state and difficult to finish: make it possible to run useful HolyC source files directly on Linux, then prove the runtime by building real things with it.
