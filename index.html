HOW IT WORKS

01

READ .HC

The frontend reads the supported HolyC language subset.

02

TRANSLATE

HolyC constructs are converted into portable C source.

03

MAP APIS

Graphics, text, input, and timing map onto Linux and SDL2.

04

RUN

Clang builds a normal native Linux executable.

ABOUT BAK-LAB

Bak-Lab is an independent open-source project. Its current purpose is to make useful HolyC source files run directly on Linux and to test that work with complete programs.
